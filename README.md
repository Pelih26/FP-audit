ui-web fpa tests 

Общая информация - развертывание проекта и запуск тестов:

1) Скопировать /.env-sample из папки tests и копию переименовать в .env

2) В .env файле прописать нужный url тестируемого стенда и дописать логин и пароль для тестов

3) Собрать и поднять докер контейнер с Playwright и Node.js с помощью команды "**make playw-build**".

4) Запустить все тесты можно командой "**make playw-test**"

5) Запустить определенный тест можно командой "**make playw-test tests/folderName/testFileName.spec.ts**" или из
интерфейса IDE

6) Посмотреть allure отчет можно командой "**make playw-allure-run**". Аllure отчет открывается на порту ``http://127.0.0.1:4815``

7) Трейсы находятся в папке test-results и посмотреть их можно через ``https://trace.playwright.dev``

8) Каждый стенд выдерживает разное кол-во параллельных потоков, поэтому в файле tests/playwright.config.ts строку
workers настраиваем сами под себя

Для автоматизаторов тестирования:

9) Перед открытием МРа (перед отправкой кода на ревью) запустить проверку кода каждого измененного файла линтером с 
помощью команды "**make playw-linter fileName**" и исправить все ошибки. Повторять это перед каждым коммитом/пушем.
Выполнить автоматическое исправление ошибок можно запустив команду "**make playw-linter-fix fileName**".
Чтобы проверить весь проект, нужно использовать команду без аргументов: "**make playw-linter**"

10) Можно запустить автоматическое исправление ошибок с помощью команды "**make playw-linter-fix fileName**"

11) Если необходимо проверить целую директорию сразу - можно использовать команду
"**make playw-linter-folder folderName**" или "**make playw-linter-folder-fix folderName**"

12) Также можно единой командой запустить все тесты сразу и проверить линтером код всего проекта автотестов: "**make playw-check**"
